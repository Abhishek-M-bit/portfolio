# Abhishek M — Portfolio

A lightweight, responsive portfolio site built with plain HTML, CSS, and JavaScript.

## Preview

Open `index.html` in a browser. No build step or package installation is needed. The Google Fonts link is optional; the page falls back to system fonts when offline.

## Profile photo and résumé

The profile image is at `assets/abhishek-profile.jpeg`. Replace it with a new image using the same filename to update the portrait.

The résumé download is at `assets/Abhishek_M_Resume.pdf`. Replace it with an updated PDF using the same filename to update the download.

## Updating profiles and projects

Edit `index.html` to update project descriptions, demo and repository links, and social profiles. `portfolio-additions.css` contains the portrait and CivicPulse project illustration styles.

## Before publishing

- Add project source or live-demo links when you have public URLs to share.
- Check the displayed email, phone, and social profile URLs.
- To publish, upload this folder to a static host such as GitHub Pages or Netlify.
